# Банковский Анализатор — Анализ операций по банковским счетам

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**Банковский Анализатор** — это консольное приложение на Python, которое анализирует историю банковских операций, строит отчёты, показывает приветствие в зависимости от времени суток, топ-5 транзакций, курсы валют и котировки акций.

---

## 📌 Описание функций

Приложение предоставляет следующие возможности:
- 🕰 Приветствие в зависимости от времени суток
- 📊 Отображение сводки по картам и транзакциям
- 💳 Топ-5 транзакций по каждой карте
- 🌍 Актуальные курсы валют (USD, EUR и др.)
- 📈 Котировки акций (например, AAPL, GOOGL)
- 📅 Фильтрация операций по дате
- 🔍 Поиск транзакций по описанию или категории

---

## 🧰 Технологии

- **Python 3.9+**
- `pandas` — для обработки данных
- `requests` — для API-запросов
- `pytest` — для тестирования
- `python-dotenv` — для загрузки переменных окружения

## 🚀 Быстрый старт

### 1. Клонируйте репозиторий
bash git clone https://github.com/TJinay-arch/response_for_bank_service.git cd bank-analyzer

### 2. Создайте виртуальное окружение
bash python -m venv source venv/bin/activate # Linux/Mac
или
venv\Scripts\activate # Windows

### 3. Установите зависимости

### 4. Настройте переменные окружения

Создайте файл `.env` на основе шаблона:
bash cp .env_template .env

Отредактируйте `.env` и добавьте свои API-ключи

> 🔑 Получите API-ключи:
> - [Exchange Rates API](https://exchangeratesapi.io/)
> - [Twelve Data (для акций)](https://twelvedata.com/)

### 5. Подготовьте данные

Поместите файл с операциями в `data/operations.xlsx`. Файл должен содержать столбцы:
- `Дата операции`
- `Описание`
- `Категория`
- `Сумма операции`

Пример данных:
| Дата операции | Описание         | Категория   | Сумма операции |
|---------------|------------------|-------------|----------------|
| 01.01.2025    | Обед в кафе      | Еда         | 500.0          |
| 02.01.2025    | Оплата интернета | Коммуналка  | 800.0          |

## ▶️ Запуск приложения
python src/main.py

Приложение вернёт JSON с:
- Приветствием
- Сводкой по картам
- Топ-5 транзакций
- Курсами валют
- Котировками акций

pytest tests/ -v
